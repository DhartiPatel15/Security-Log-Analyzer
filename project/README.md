# Security Log Analyzer Dashboard

## Project Description
This project analyzes security log files and detects suspicious activities such as:
- Failed Login Attempts
- Successful Logins
- Access Denied Events
- Suspicious IP Addresses

## Features
- Reads log files
- Generates Security Report
- Creates Bar Chart
- Creates Pie Chart
- Detects suspicious activities

## Technologies Used
- Python
- Matplotlib
